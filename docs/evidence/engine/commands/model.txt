Resolve or list available models across providers

Usage: codewhale model [OPTIONS] <COMMAND>

Commands:
  list     
  resolve  
  set      Set the default model (e.g. "deepseek-v4-pro"; "pro"/"flash" on routes that serve DeepSeek)
  help     Print this message or the help of the given subcommand(s)

Options:
      --enable <FEATURE>   Enable a feature for this run (repeatable)
      --disable <FEATURE>  Disable a feature for this run (repeatable)
  -h, --help               Print help
