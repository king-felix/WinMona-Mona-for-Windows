Manage durable Agent fleet runs

Usage: codewhale fleet [OPTIONS] [ARGS]...

Arguments:
  [ARGS]...  Arguments and options forwarded to the command

Options:
      --enable <FEATURE>   Enable a feature for this run (repeatable)
      --disable <FEATURE>  Disable a feature for this run (repeatable)
  -h, --help               Print help

Examples:
  codewhale fleet init
  codewhale fleet run tasks.json --max-workers 4
  codewhale fleet status

The durable ledger `.codewhale/fleet.jsonl`, saved rosters `fleets/<name>.toml`,
the `[fleet]` and `[fleets.*]` config tables, and `workflow run --fleet` keep
the Fleet name across versions.
